# juniors bootcamp examples

Данный репозиторий содержит примеры реализации проектов для платформы Juniors Bootcamp. Juniors Bootcamp — это платформа для практики, где вы проходите задания, максимально приближенные к реальным рабочим сценариям, и постепенно прокачиваете навыки через опыт. В рамках платформы доступны задания. В этом репозитории будут собираться примеры решений, которые можно использовать как ориентир при выполнении заданий.
