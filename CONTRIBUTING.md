# Добавить проект

Решили задание Juniors Bootcamp и хотите показать результат в [галерее проектов](https://juniorsbootcamp.ru/projects)? Создайте [Issue в этом репозитории](https://github.com/siberiacancode/juniors-bootcamp-examples/issues/new), а затем отправьте PR с копией решения и новой записью в каталоге.

## 1. Создайте Issue

Укажите GitHub username автора, название проекта, задание (`delivery`, `cars`, `cinema`, `pizza` или `games`), framework (`react`, `next`, `vue`, `nuxt` или `angular`) и ссылку на исходный репозиторий. По желанию добавьте ссылку на работающее демо и скриншот интерфейса. Репозиторий с вашим решением должен быть доступен для проверки.

## 2. Подготовьте PR

1. Сделайте fork этого репозитория и создайте ветку для проекта.
2. Добавьте копию решения, например в `cinema/3/`. Если есть скриншот, сохраните его в корневой папке `images/`.
3. **Самостоятельно добавьте запись о своём проекте в конец массива** корневого `projects.json`. Сохраняйте порядок существующих записей. `path` должен указывать на добавленную в PR копию решения, а `preview` — на добавленный файл в `images/`.
4. Откройте PR и укажите в его описании ссылку на созданный Issue.

### Поля `projects.json`

| Поле        | Тип      | Обязательно | Что указывать                                                                                                                                    |
| ----------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `username`  | `string` | Да          | GitHub username автора без `@`.                                                                                                                  |
| `name`      | `string` | Да          | Название проекта. Пустая строка для новых проектов не допускается.                                                                               |
| `task`      | `string` | Да          | `delivery`, `cars`, `cinema`, `pizza` или `games`.                                                                                               |
| `framework` | `string` | Да          | `react`, `next`, `vue`, `nuxt` или `angular`.                                                                                                    |
| `path`      | `string` | Да          | Путь к копии решения **в этом репозитории**, например `cinema/3`. Ссылка на исходный репозиторий указывается в Issue, не здесь.                  |
| `preview`   | `string` | Нет         | Путь к скриншоту **в этом репозитории**, начинающийся с `images/`, например `images/example-cinema.png`. Если скриншота нет, не добавляйте поле. |

Пример записи, которую нужно поставить **последней** в массиве `projects.json`:

```json
{
  "username": "example-user",
  "name": "Кинотеатр",
  "task": "cinema",
  "framework": "next",
  "path": "cinema/3",
  "preview": "images/example-cinema.png"
}
```

## 3. Дождитесь проверки

Сопровождающий проверит Issue и PR, затем объединит PR и закроет Issue. После этого он запустит `sync-projects` в репозитории портала и закоммитит обновлённый снимок. Проект появится на сайте после следующей сборки портала.
